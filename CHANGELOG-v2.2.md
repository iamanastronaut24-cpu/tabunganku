# TABUNGANKU v2.2

## Perubahan
- Penyegaran visual dengan gaya premium fintech: dark forest hero, aksen lime, kartu lebih lembut, dan navigasi mobile translucent.
- Tombol profil `D` membuka halaman Tentang TABUNGANKU.
- Halaman Tentang berisi deskripsi aplikasi, fitur utama, versi, dan credit `Created by Dedi Hermans`.
- Credit di sidebar lama dihilangkan agar tidak tampil di luar halaman Tentang.
- Cache service worker dinaikkan ke v2.2 agar perangkat mengambil aset terbaru.

## Dipertahankan
- Google Apps Script backend (`google-apps-script/Code.gs`).
- Cloudflare Pages Function (`functions/api/sync.js`).
- Struktur data, transaksi, backup/pemulihan, sinkronisasi cloud, dan antrean offline.
